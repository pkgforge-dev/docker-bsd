## ⚠ What a session record is for, and what it is not

⭐ **It is for the numbers and the dead ends.** A later session should be able
to read one and know what was already tried, what it cost, and which of the
claims in the tree came out of it.

⛔ **It is not the work order.** That is
[`../../TODO/PROGRESS.md`](../../TODO/PROGRESS.md), it is rewritten every
session, and it is the only file that carries one. A session record that starts
being consulted for "what next" is a second work order going stale.

⛔ **And it is not corrected in place.** If a later measurement disproves
something a session record claims, the correction goes in the document that
carries the claim today, underneath the claim. The record keeps its wording,
because the point of it is what was believed at the time.
